Manifesto

IA não substitui — expande.

A gente não acredita em IA que apaga a pessoa do meio. Acredita em IA que amplifica quem você já é, com ferramentas que entendem o seu contexto e respeitam o seu trabalho.

AI-first, não AI-only.

A IA é o núcleo dos produtos, mas as pessoas continuam no centro. Cada decisão de UX prioriza autonomia, transparência e propriedade dos dados.

Local-first por padrão.

Seus dados não saem da sua máquina, a não ser que você queira. Ollama, modelos próprios e infra própria — opcionalmente nuvem.

Aberto onde dá pra ser.

Código aberto, pesos abertos, integrações abertas. Quando o produto é proprietário, a interoperabilidade ainda é.

Produtos

Um ecossistema, não um app.

Cada produto da .mtz resolve uma camada — execução, comunicação, conhecimento — e conversa com os outros via APIs e agentes.

/mortaza.ai

Agente de código no seu WhatsApp

Mande mensagem pelo WhatsApp e o agente lê arquivos, edita código, roda comandos no seu servidor — e responde no mesmo chat. Suporta Claude API e Ollama local, intercambiáveis por variável de ambiente. Cada contato em workspace isolado.

  • Webhook Evolution API
  • Sessões por contato (LRU)
  • Claude 4.x + Ollama
  • Docker compose enxuto
$ docker compose up -d
→ Evolution webhook → agente → WhatsApp
✓ respondendo em <2s
/mtzcode

Assistente de código 100% local

Agent loop com tool calling, RAG semântico e skills plugáveis. Roda no Ollama da sua máquina. Sem custos por uso, sem dado saindo.
